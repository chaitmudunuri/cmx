Installation

CMX runs on macOS, Linux and Windows. Prebuilt binaries exist for macOS on Apple Silicon; the other platforms build from source in about two minutes.

macOS#

1. Download#

Grab the .dmg from the latest release, or see the download page for a copy-pasteable command.

2. Install#

Open the .dmg and drag cmx editor into Applications.

3. First launch#

CMX is not code-signed, so macOS blocks it on first run. Either right-click the app and choose Open, or run:

xattr -dr com.apple.quarantine "/Applications/cmx editor.app"

4. Open a folder#

Launch CMX, then use Open folder in the file explorer to point it at a project. CMX restores your last session — open tabs, folder and untitled buffers — on next launch.

Linux#

1. Install the toolchain#

CMX renders through WebKitGTK, so its build and runtime dependencies must be present:

# Debian / Ubuntu
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
  libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev

# Fedora
sudo dnf install webkit2gtk4.1-devel openssl-devel libxdo-devel \
  libappindicator-gtk3-devel librsvg2-devel

2. Install Rust and Node#

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

3. Build#

git clone https://github.com/chaitmudunuri/cmx.git
cd cmx
corepack enable && corepack prepare pnpm@latest --activate
pnpm install
pnpm tauri build

Bundles land in src-tauri/target/release/bundle/.

Windows#

1. Install the prerequisites#

Install Rust and Node 20+. The WebView2 runtime is pre-installed on Windows 11; on Windows 10 install the Evergreen runtime.

Building the NSIS installer additionally needs the Visual Studio Build Tools with the Desktop development with C++ workload.

2. Build#

git clone https://github.com/chaitmudunuri/cmx.git
cd cmx
corepack enable
pnpm install
pnpm tauri dev      # try it without a full bundle

3. Package#

pnpm tauri build --bundles nsis

Updating#

CMX does not self-update. Replace the binary or re-run the installer from the latest release. Your settings live in local storage and survive an upgrade.

If something goes wrong#

See troubleshooting. If it is not covered there, open an issue with your platform and version.
