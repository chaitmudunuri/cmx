Troubleshooting

The problems people actually hit, and what to do about them. If yours is not here, open an issue — Linux and Windows reports are especially welcome, since neither platform has a prebuilt binary yet.

macOS

"CMX is damaged and can't be opened"

Gatekeeper is blocking an unsigned build. Right-click the app and choose Open, or:

xattr -dr com.apple.quarantine "/Applications/cmx editor.app"

Blank or white window

macOS caches web content. Quit CMX fully and relaunch. If it persists, clear the webview cache by removing ~/Library/WebKit/com.cmx.editor — settings are stored separately and will survive.

The app is slow to start on first launch

macOS Gatekeeper checks the unsigned binary on first launch only. Subsequent launches skip it.

Linux

libwebkit2gtk-4.1.so.0: cannot open shared object file

WebKitGTK 4.1 is missing or too old. Install the development packages — see Linux installation.

Blank window

Check that the appindicator and librsvg libraries are present; some minimal desktop images omit them. Also confirm the session is not running Wayland without a working WebKitGTK portal.

Windows

The window never appears

The WebView2 runtime is missing or broken. Install the Evergreen runtime and relaunch.

Build fails with a linker error

Install the Visual Studio Build Tools with the Desktop development with C++ workload, then restart the shell so the toolchain is on PATH.

Any platform

Large file opened slowly, or shows a FAST badge

This is working as designed. Files over 1.5 MB or 25,000 lines drop into fast mode with parsing off. See large files.

Search returns nothing for a file I know contains the text

Workspace search honours .gitignore and skips hidden files. A file excluded by either will not match — that is deliberate, not a bug.

Accented or pasted characters display incorrectly

Check the encoding indicator in the status bar. CMX opens files as UTF-8 and falls back gracefully; a mis-encoded file may need re-saving as UTF-8 in another tool.

CMX will not close

Unsaved changes prompt for confirmation. Esc dismisses dialogs and never cancels your typing, so it will not discard a buffer for you.

Reporting a bug

Include your CMX version, OS and architecture, what you expected, what happened, and minimal reproduction steps. Logs from the developer console help. Use the bug report template.
