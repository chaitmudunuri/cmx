Configuration

Open settings with ⌘,. Changes save automatically — there is no save button and no settings file to edit.

Settings#

SettingOptionsNotes
Vim keybindingsOff / Friendly / ExpertOff by default. Also switchable from the status-bar pill.
Text sizeIncrementsAlso on ⌘=, ⌘- and ⌘0.
Tab size2, 4 or 8Applies to new indentation; visual guides follow.
FontSix bundled monospace facesPreviewed live as you move through the list.
ThemeDark or LightSwitches instantly without losing state, cursor position or scroll.
Word wrapOn or offAlso on ⌥Z. Shown in the status bar.

Fonts#

CMX bundles six monospace faces and renders them without a network round trip:

  • JetBrains Mono
  • Fira Code
  • Source Code Pro
  • Cascadia Code
  • SF Mono / Menlo
  • Consolas

JetBrains Mono is the default and is the one with ligatures enabled.

Where settings live#

Settings are written to web storage in the app's local data directory, keyed by cmx_* entries. They persist across upgrades and are not synced between machines. CMX deliberately has no account system and sends no telemetry, so there is nothing to sign in to and nothing to lose.

Portable configuration profiles are on the roadmap, not yet implemented. If you want settings under version control today, note the storage keys above and script them.

Theme#

Two themes ship with CMX: a dark theme and a GitHub-style light theme. CMX applies the theme before first paint, so there is no flash of the wrong colours on launch.
