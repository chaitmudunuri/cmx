Vim mode

When Vim mode is enabled, CMX's own bindings stay available and modal editing takes over in the editor. Ex commands include:

:w    save          :noh   clear search highlight
:q    close         :bd    close buffer
:q!   close, discard changes
:wq   save and close
:x    save and close
:e    reload
:new  new buffer

The status bar shows the current mode (NORMAL, INSERT, VISUAL), and a which-key style hint bar appears while Friendly or Expert mode is active.

See Vim mode for what each level includes.
