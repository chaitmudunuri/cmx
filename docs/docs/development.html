Developer setup

Build CMX from source, run the tests, and profile a release build. The repository is at https://github.com/chaitmudunuri/cmx.

Prerequisites#

  • Node 20+ with pnpm
  • Rust stable — macOS also needs xcode-select --install
  • Linux also needs the WebKitGTK toolchain — see Linux installation

The full platform list is maintained by the Tauri project.

Run it#

git clone https://github.com/chaitmudunuri/cmx.git
cd cmx
pnpm install
pnpm tauri dev      # Vite + Tauri with hot reload at http://127.0.0.1:1420

Useful while developing:

pnpm dev           # frontend only, no native shell
pnpm build         # production frontend bundle
pnpm tauri build   # full release bundles for this platform

Checks#

npx tsc --noEmit                    # frontend typecheck
pnpm build                           # production build
cd src-tauri && cargo test         # Rust unit tests
cd src-tauri && cargo clippy -- -D warnings

CI runs the typecheck, the frontend build and the Rust tests on every push across Linux, macOS and Windows.

Benchmarks#

pnpm tauri build     # the harness profiles the release binary
pnpm bench --runs 5

The harness samples the running binary and prints medians, plus a machine-readable __CMX_BENCH__ JSON line. Full methodology is on the performance page.

Project layout#

PathContents
src/Solid.js frontend. App.tsx wires shortcuts, themes, modals and layout.
src/components/Editor.tsx owns the CodeMirror lifecycle; Sidebar.tsx, QuickOpen.tsx, LivePreview.tsx and the status and title bars.
src/stores/editor.tsCentral signal store: files, tree, search, settings, session.
src-tauri/src/main.rs sets up Tauri and native menus; commands.rs holds file IO, directory listing, file search, workspace search and preview.
scripts/Benchmark harness, screenshot capture, and the generator for this website and the social preview.
docs/This website, plus the README screenshots.
