CMX

A native-feeling code editor with Vim mode, workspace search, and live preview. No Electron, no bundled browser.

A ~7 MB binary, ~95 MB resident memory and a ~2.4 s cold start — because CMX renders in the OS webview instead of bundling a browser.

Download for macOS All platforms Source on GitHub

Why CMX#

Most editors make you choose between native feel and speed. Electron apps feel native but ship a browser runtime; web editors are fast but live in a tab. CMX uses the operating system's own webview, so it gets both without owning a browser.

No bundled browser#

WebKit on macOS, WebKitGTK on Linux, WebView2 on Windows. Nothing extra to download, patch or ship.

Vim mode, three levels#

Off by default. Friendly adds hints and a forgiving Ex set; Expert gives the full motion vocabulary.

Workspace search#

Ripgrep's ignore walker, built in. Respects .gitignore with nothing to install.

Live preview#

Markdown, HTML and SVG rendered beside the source, split by a draggable resizer.

Quick Open#

A ranked file finder on ⌘P and the command palette on ⌘⇧P.

Large-file fast mode#

Files past 1.5 MB or 25,000 lines drop to fast mode automatically, with a badge so you know.

Get CMX#

Prebuilt binaries exist for macOS on Apple Silicon today. Linux and Windows build cleanly from source, and packaged installers for all three platforms are the next release milestone.
