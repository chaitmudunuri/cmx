Features

Everything CMX does — and, at the end, what it deliberately leaves out. Figures are on the performance page.

Editing#

CodeMirror 6 core#

The mature editing engine, not a reimplementation.

  • Multiple cursors
  • Bracket matching and closing
  • Code folding
  • Search-and-replace panel
  • Highlighted selection matches

14 grammars, on demand#

Language packs load when a file needs them. Opening a Rust file never waits on the Python grammar.

  • JS/TS
  • Python
  • Rust
  • C/C++
  • Java
  • Go
  • HTML
  • CSS
  • JSON
  • Markdown
  • SQL
  • XML
  • YAML
  • Shell
  • Dockerfile

Markdown, properly#

Headings, emphasis, code, quotes, lists and links — with fenced code blocks syntax-highlighted rather than dumped as plain text.

Comfortable defaults#

The small things you notice after an hour.

  • Tab size 2, 4 or 8
  • Word wrap
  • Zoom in / out / reset
  • Six bundled monospace fonts

Configuration →

Large files#

Files past 1.5 MB or 25,000 lines drop into fast mode: parsing and decorative extras switch off so scrolling and editing stay smooth. A FAST badge in the status bar always tells you which mode you are in, so it is never a mystery.

Vim mode#

Three levels, switched from the status-bar pill or the command palette.

Off default#

A plain editor. Nothing is intercepted.

Friendly#

Hints plus a forgiving Ex command set.

Expert#

The full motion vocabulary.

Ex commands:

  • :wsave
  • :qclose
  • :q!close, discard
  • :wqsave and close
  • :xsave and close
  • :ereload
  • :nohclear highlight
  • :bdclose buffer
  • :newnew buffer

A which-key style hint bar appears alongside a mode pill reading NORMAL INSERT or VISUAL.

Navigation#

File explorer#

Create, rename and delete files and folders inline; reveal in Finder or Explorer; open and close a folder.

  • The tree patches itself in place
  • Saving a file never collapses the sidebar

Quick Open ⌘P#

A ranked file finder over the open workspace, with filename hits ranked ahead of directory hits.

  • ⌘⇧P or F1 — command palette
  • :line[,col] — jump to a position

Workspace search ⌘⇧F#

Every file in the workspace, grouped by file with two lines of context and the matched text highlighted.

  • 150 ms debounce
  • In-flight searches cancel as you keep typing
  • Honours .gitignore and skips hidden files
  • No external rg binary needed

Tabs#

Dirty-state dots, per-tab scroll and memory.

  • Close one / right / others / all
  • Confirmation before discarding changes

Live preview#

Press ⌘⇧V to render the document beside the source, split by a resizer you can drag and reset with a double-click.

Markdown#

Debounced, GitHub-flavored rendering.

HTML#

Rendered in a sandboxed <iframe>, so the document cannot reach the filesystem.

SVG#

Previewed in place.

Status bar#

Vim mode pill, detected language, Ln/Col that jumps to Go to Line and reports the document's total line count, selection size, word-wrap state, encoding, and loading and fast-mode indicators.

What CMX does not do#

No native-code plugins#

CMX renders in the OS webview. Plugins that run arbitrary native code would undercut the reason it ships no browser runtime.

No terminal multiplexer#

tmux and the terminal already do this better.

No cloud sync#

Settings are a small file. Put it in your dotfiles repository.

The roadmap records what is being considered and why.
