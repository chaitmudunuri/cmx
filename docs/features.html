  1. Features

Features

Everything CMX does, and what it deliberately leaves out. Measurements are on the performance page.

Editing

  • CodeMirror 6 core. Multiple cursors, bracket matching and closing, folding, a search-and-replace panel, highlighted selection matches and an active-line marker.
  • 14 language grammars, loaded on demand. JavaScript/TypeScript, Python, Rust, C/C++, Java, Go (via the C++ grammar), HTML, CSS, JSON, Markdown, SQL, XML, YAML, Shell and Dockerfile. Opening a Rust file never waits on the Python grammar.
  • Markdown with highlighted fenced code blocks — headings, emphasis, code, quotes, lists and links.
  • Tab size 2, 4 or 8; word wrap; zoom in, out and reset; six bundled monospace fonts. See configuration.

Large files

Files over 1.5 MB or 25,000 lines automatically drop into fast mode: parsing and decorative extras switch off so scrolling and editing stay smooth, and a ⚡ FAST badge appears in the status bar so you always know which mode you are in. Reopening a file above the threshold always starts in fast mode.

Vim mode

Three levels, switched from the status-bar pill or the command palette.

LevelWhat you get
Off defaultA plain editor. Nothing is intercepted.
FriendlyHints plus a forgiving Ex command set.
ExpertThe full motion vocabulary.

Ex commands: :w :q :q! :wq :x :e :noh :bd :new, alongside a which-key style hint bar and a mode pill reading NORMAL, INSERT or VISUAL.

Navigation

File explorer

Create, rename and delete files and folders inline; reveal in Finder or Explorer; open and close a folder. The tree patches itself in place, so saving a file does not collapse and re-expand the whole sidebar.

Quick Open

A ranked file finder over the open workspace on ⌘P, with filename hits ranked ahead of directory hits. The command palette is on ⌘⇧P or F1, and :line[,col] jumps straight to a position.

Workspace search

⌘⇧F searches every file in the workspace and groups matches by file with two lines of surrounding context. Results highlight the matched text and update on a 150 ms debounce — and when you keep typing, in-flight searches are cancelled rather than queued.

Search is implemented in Rust on ripgrep's ignore crate. It honours .gitignore and global excludes and skips hidden files out of the box, and needs no external rg binary installed.

Tabs

Dirty-state dots, per-tab scroll and memory, close one / right / others / all, and a confirmation before discarding unsaved changes.

Live preview

⌘⇧V renders the document beside the source, split by a resizer you can drag and reset with a double-click.

  • Markdown — debounced, GitHub-flavored rendering.
  • HTML — rendered in a sandboxed <iframe>, so the document cannot reach the filesystem.
  • SVG — previewed in place.

Status bar

Vim mode pill, detected language, Ln/Col that jumps to Go to Line and reports the document's total line count, selection size, word-wrap state, encoding, and loading and fast-mode indicators.

What CMX does not do

There is no plugin system that runs arbitrary native code, no built-in terminal multiplexer, and no cloud sync — settings are a small file that belongs in your dotfiles repository. The roadmap records what is being considered and why.

CMX is MIT licensed and free software. Built with Tauri 2, CodeMirror 6 and Solid.js, in Rust. The GitHub repository is the source of truth for the code.
