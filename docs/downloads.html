Linux and Windows are not second-class. All three platforms build and run today, and the CI workflow builds and tests all three on every push. Prebuilt installers for Linux and Windows are tracked as the next release milestone.

macOS — Apple Silicon

Download the .dmg, then drag cmx editor into Applications:

curl -fLo cmx.dmg \
  https://github.com/chaitmudunuri/cmx/releases/download/v0.1.0/cmx.editor_0.1.0_aarch64.dmg
hdiutil attach cmx.dmg && cp -R "cmx editor.app" /Applications/

Launch it from Applications, or from the terminal:

open -a "cmx editor" ~/your/project

macOS builds are unsigned. Gatekeeper will refuse to open it on first launch. Right-click the app and choose Open, or run:
xattr -dr com.apple.quarantine "/Applications/cmx editor.app"
Code signing and notarization are on the roadmap.

Linux

No .deb or AppImage is published yet, so build from source. Install the WebKitGTK toolchain first:

# Debian / Ubuntu
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
  libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev

# Fedora
sudo dnf install webkit2gtk4.1-devel openssl-devel libxdo-devel \
  libappindicator-gtk3-devel librsvg2-devel

Then follow developer setup. You can produce local packages immediately with pnpm tauri build, which writes .deb, .rpm and AppImage to src-tauri/target/release/bundle/.

Windows

No installer is published yet, so build from source. You need Rust, Node 20+ and the WebView2 runtime, which is pre-installed on Windows 11. From PowerShell:

git clone https://github.com/chaitmudunuri/cmx.git
cd cmx
corepack enable
pnpm install
pnpm tauri dev

Verify what you downloaded

Every published release includes a CHECKSUMS.txt:

sha256sum -c CHECKSUMS.txt

If a checksum does not match, do not run the file — report it.

Other systems

Package managers such as Homebrew, Scoop and the AUR are not yet publishing CMX. Please do not add unofficial packages on the project's behalf — open an issue and we will help scope an official one. The documentation covers configuration once it is running.
